# 使用说明

## 一、这个技能是什么

一个**排障技能包**，不是教程。

它假设你已经在做片子了：剧本有了、资产图有了、开始生成或剪辑了，然后卡住。它按「你看到什么症状」分流到 13 条对应处理路径，每条路径给出动作、判据和失效边界。

它不管的事：

- 从零写剧本、改编小说 → 归编剧
- 选题、题材判断、市场分析 → 只有一条经验（家庭伦理最热、女性向是空白），不足以支撑决策
- 白膜怎么做、四锁用什么工具 → 原课没讲，技能里也不编

## 二、安装

整个目录就是一个标准 Agent Skill（`SKILL.md` 的 frontmatter 符合 Agent Skills 规范）。

**Claude Code**

```bash
git clone <repo-url> ~/.claude/skills/ai-shortdrama-production
```

**DSH / DS Bot / 其他兼容 agent**

```bash
git clone <repo-url> ~/.agents/skills/ai-shortdrama-production
```

**项目内共享**（团队成员克隆同一仓库即可）

```bash
git clone <repo-url> .agents/skills/ai-shortdrama-production
```

安装后的目录长这样，`SKILL.md` 必须在**技能目录的第一层**：

```
ai-shortdrama-production/
├── SKILL.md                    ← 必须在第一层
├── BUILD_MANIFEST.json
└── references/
    ├── overview.md
    ├── capability-index.md
    ├── cheatsheet.md
    ├── glossary.md
    └── capabilities/*.md
```

## 三、怎么用

### 3.1 自动命中（推荐）

不用记技能名，直接说症状。agent 读到 `SKILL.md` 的路由表后自己对上：

```
六个人怎么排，老是穿模
两卡接不上，下一卡的脸变了
提示词改十遍了还是不对
参考视频是日语，声音很怪
做封面的时候人物全乱了
```

### 3.2 点名强制

症状描述模糊、或想确认它有没有被加载时，直接点名：

```
用 ai-shortdrama-production 看下我这个镜头
```

### 3.3 查规则原文

想核对某条结论的出处：

```
尾帧衔接那条的原文是怎么说的
```

会走 `references/cheatsheet.md` 或对应能力卡，把 `R 原文摘录` 给你。

## 四、四个完整例子

### 例 1：多人场景

**你说**

> 6P 那个镜头人物全堆一起了，脸也串了

**它做什么**

加载 `multi-person-layout` + `video-ref-guard`，按 `E 执行方式` 给出：

| 动作 | 内容 |
|---|---|
| 画幅 | 4 人以上从 9:16 改 **16:9**，竖屏物理上装不下 |
| 身份 | 每人分配 **ID**，站位写死（左右/前后/朝向） |
| 参考 | 每个 ID 单独绑资产图，一张图塞多人必串 |
| 参考视频 | 只截**单镜头**，整段 30 秒丢进去必串脸 |

**判据**：生成结果里每个人的身份、位置与配置一一对应，无穿模。

### 例 2：接不上

**你说**

> 第二卡接第一卡，人物脸变了

**它做什么**

加载 `tail-frame-handoff`，核心一句：**只放尾帧不够，人物资产必须同时放进去**。

六步：导尾帧 → 检查该帧位置/服装/道具/光线 → 当下一卡首帧 → **加入人物资产参考** → 描述从当前状态继续的动作 → 生成后从接缝前几秒回放裁掉重复停顿。

### 例 3：提示词怎么改都不对

**你说**

> 我写了"在女主身上"，模型一直不执行

**它做什么**

加载 `resolve-by-reference`，判断这是**通道选错**而不是措辞问题：

1. 确认提示词本身没有逻辑错误
2. 判断失效类型：外观/位置/姿态 → 用图；节奏/声音/动作过程 → 继续用文字
3. 找一张符合预期的参考图
4. **保持提示词不变**，只加参考图
5. 重新生成

同时会提醒你 `prompt-minimalism`：加图之后，原本那些描述外观的词可以删掉。

### 例 4：整段有穿帮

**你说**

> 30 秒里总有几秒是崩的，整段重跑太费

**它做什么**

加载 `salvage-frame`：逐段定位不穿帮的区间 → 截那一帧（分辨率要够）→ 当下一段首帧 → 补齐前后镜头 → 后期拼接。

**判据**：成片不含穿帮，且没有整段重跑。

## 五、每张能力卡怎么读

固定六段，顺序有原因：

| 段 | 内容 | 怎么用 |
|---|---|---|
| `R` 原文摘录 | 讲者的原话 | 想核对出处、或判断有没有被转述走样时看这段 |
| `I` 我的理解 | 为什么这么做 | 理解机制，才好在变体场景里迁移 |
| `A1` 案例 | 原文里的真实场景 | 找和自己最像的那个 |
| `A2` 与相邻能力的区分 | 和哪张卡容易混 | 症状重合时靠这段决定先看哪张 |
| `E` 执行方式 | 输入 / 步骤 / 输出 / 完成标准 | **真正动手照这段做** |
| `B` 边界 | 什么时候失效 | 照做完没效果，回来看这段 |

## 六、给 agent 的东西越多，产出越准

| 你提供 | 能得到 |
|---|---|
| 一句症状 | 方法和步骤 |
| 症状 + 卡住的**提示词原文** | 改后的短提示词（删掉交给图的部分） |
| 症状 + **截图 / 视频帧** | 判断是构图问题、特征污染，还是单纯没抽到 |
| 剧本片段 + 资产图 | 完整节点配置（画幅 / ID / 站位 / 参考绑定） |

## 七、装了没反应怎么排查

1. **确认目录层级**：`SKILL.md` 必须在 `<技能目录>/SKILL.md`，多套一层（比如 `ai-shortdrama-production/ai-shortdrama-production/SKILL.md`）就读不到
2. **确认 frontmatter**：`SKILL.md` 开头的 `---` 块里要有 `name` 和 `description`，`description` 写的是「什么时候用」，agent 靠它做触发判断
3. **确认技能目录位置**：`~/.claude/skills/` 或 `~/.agents/skills/`，看你用的 agent
4. **重启 agent**：多数实现只在启动时扫描技能目录
5. **点名测试**：直接说「用 ai-shortdrama-production 帮我看看」，能响应说明加载成功

## 八、它不承诺什么

- 不给成功率、返工次数、耗时的数字——原文没有，这里也不编
- 不给具体工具的参数——原文用的是特定平台，换工具需要重验
- 不给「四锁」的实现方法——原文只给了维度，没给手段
- 不判断你的片子好不好看——那是剧本和审美问题
