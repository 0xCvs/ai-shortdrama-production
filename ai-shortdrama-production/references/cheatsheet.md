# 决策规则速查 — AI 短剧制作实战课（吴明直播）

| 能力 | 一句话规则 |
|---|---|
| 提示词失效时转用图像参考 | 同一份提示词反复生成不对时，保持提示词不变，加一张参考图重新生成 |
| 提示词精简原则 | 提示词只写这次要发生的变化，外观交给参考图，写太多模型只吃一半 |
| 静态姿势图前置 | 反复抽卡出不来时，先生成静态姿势图锁定构图与接触点，再用它跑视频 |
| 视频参考防串脸 | 视频参考会把对方角色特征带进来，用白膜、四锁或缩短参考范围解决 |
| 多人场景重构 | 四人以上必须改 16:9，每个角色给 ID 和明确站位，把人物写死 |
| 尾帧衔接 | 把上一卡尾帧当下一卡首帧，同时必须放入人物资产，否则人物会变 |
| 抽卡补救：截可用帧 | 三十秒里总有几秒不穿帮，截那一帧当新起点，不要整段重跑 |
| 复杂设定先做主体图 | 约束太多放不进一句话时，先做一张主体图承载全部约束，再从它出发 |
| 九宫格背景 + 单独主角 | 九宫格只当场面背景，主角必须单独丢参考，直接出视频会丢主角 |
| 插入画面单独生成再拼 | 插入镜头单独剪出来出 7 秒反复抽卡，前后段保留，后期拼接 |
| 音效替代：去掉参考音频自己写 | 参考视频的音频要去掉，叫声呼吸声用提示词写，明确不要叠音 |
| 上下文窗口重置 | 对话窗口用久了会漏信息、变慢，新开窗口重放母提示词校准 |
| 封面参考法 | 找现成封面当参考，多人封面先手画站位草图再交给模型 |

> 速查只给结论；需要原文依据、案例或反例时读对应能力卡。
