## 二、主旨

**做 AI 短剧的真正门槛不在提示词，在“能不能判断观众想看什么”，以及“出了问题怎么救”。**

吴明的原话："真正的逻辑核心，还是你对剧本的理解。" "核心还是自己多练习。"

视频的独特价值在于：**它不是讲方法论，而是讲实战中的翻车和补救。**

## 三、内容结构（讲者实际的组织方式）

视频是口语直播，没有章节，但内容自然分成五块：

```
一、制作流水线回顾（约 5 分钟）
   剧本理解 → 删重复 → 与编剧沟通 → Grok 拆解 → 资产图 → 分镜 → 画布 → 生成

二、参考图实战（约 40 分钟，核心）
   提示词搞不定的，用参考图解决

三、视频参考与串脸问题（约 15 分钟）
   白膜/深度图、四锁、单镜头参考

四、衔接与抽卡补救（约 10 分钟）
   尾帧接首帧、截不穿帮的帧

五、学员答疑（约 15 分钟）
   题材判断、女性市场、封面、上下文管理、Skill 取舍
```

## 四、可提炼的方法单元（18 条）

### A. 参考图优先原则（最高价值）

**1. 提示词失效时加图像参考**
同一份提示词，加一张参考图，模型立刻"听话"。这是全课反复出现的核心手法：
- 白板/熟脸没有填进去 → 加参考图
- 表情不对 → 加表情参考图
- 插入画面没感觉 → 加插入参考图
- 口交跑了方向 → 加参考图
- 模型跑不出某种姿势 → 直接丢图让它参考

**2. 提示词极简原则**
"提示词其实不需要太多、太复杂。太复杂的话，模型可能会吃你一半。"
- 皮肤质感：一句"全身皮肤有水光"就够
- 反面：写太多形容词，模型跑偏
- 但音效/节奏这类必须写清（"有节奏的插入""汗水""叫声"）

**3. 姿势图前置**
反复抽不到卡时，先做静态姿势图，再拿姿势图去跑视频。
- 好处：构图和手部关系先锁死
- 效果：一卡就能出来，不用反复抽卡

**4. 复杂设定先做主体图**
剧本复杂（捆绑+口塞+多部位固定）时，模型怎么聊都生不出来。
做法：先做一张主体图，以它为基础再生成。怕穿帮就把眼睛遮住、形象不变。
"这样可以省很多次抽卡。"

### B. 视频参考与串脸

**5. 视频参考会带错角色特征**
用视频参考时，容易把参考里角色的尺寸/特征带进你的角色（"上集凶那么小，这集这么大"）。

**6. 白膜 / 深度图解法**
用白膜（深度图）替代真人参考，只传递动作不传递外观。
缺点：麻烦、要装。
替代：不想用白膜的，用"锁定类"参考。

**7. 四锁原则**
锁脸、锁身材、锁发型、锁位置。
"参考的时候千万不要 30 秒这样丢，就一个镜头就行了。"

**8. 想更真：男主不参考**
追求极致真实时，男主干脆不用参考，只用前几秒。
"后面的人物肯定是不对的，你把想用的那几秒截下来就够了。"

### C. 多人场景

**9. 多人必须 16:9**
6P 这类场景，9:16 画面太窄，人物堆不下。要改 16:9。

**10. 人物"写死"**
每个人物给 ID，明确每个站位，写清楚。不需要更多复杂描述。

**11. 九宫格只做背景**
九宫格/群像图适合运动会、群架这类场景，但只当背景模板用，主角仍要单独丢参考图。
"直接九宫格出视频，肯定不行。"

### D. 衔接与补救

**12. 尾帧接首帧 + 资产不能丢**
下一卡除了尾帧，**人物资产必须一起放进去**，否则人物会变。

**13. 抽卡补救法**
30 秒里总有几秒不穿帮。把那一帧截图下来，用它去生成下一段，而不是整段重来。

**14. 音效不参考音频**
参考视频的音频（外语、环境音）要去掉，用提示词写：叫声、呼吸声、身体起伏、水声、摩擦声、不要叠音。

**15. 插入画面单独出**
插入那一段看起来假，就单独剪出来出一个 7 秒的反复抽卡，后面的保留。

### E. 判断与市场

**16. 题材判断**
- 家庭伦理最热，但做不出来的也多
- 女性向是空白市场，需求真实存在（有人愿意定制付费）
- 猎奇能吸引人，但不能太恐怖

**17. 人物资产要有"缺点"**
"她不漂亮，但她身材好"——反而是卖点。
主角要有性格（糯糯的、胆子大），观众才觉得像真人。
配角可以当"总肥肥大"那种，主角不要。

**18. 色情比例约 30%**
第一集带色感但不纯肉；核心设定、世界观要先放前面；真正到肉的地方占三成。

## 五、核心概念（视频里的说法）

| 说法 | 含义 |
|---|---|
| 丢参考 | 给模型加图像/视频参考，替代文字描述 |
| 听话 | 模型按预期生成 |
| 抽卡 | 反复生成直到出可用的 |
| 穿帮 | 人物、道具、空间关系出错 |
| 白膜 / 深度图 | 只传动作、不传外观的参考图 |
| 四锁 | 锁脸、锁身材、锁发型、锁位置 |
| 写死 | 用 ID 和站位把人物固定住 |
| 垫图 | 把图放进节点作参考 |
| 前戏 / 插入 | 生成时的两个阶段，插入单独处理 |

## 六、批判与局限

**成立的部分**
- "提示词搞不定就加参考图"是全课最有价值的判断，且可验证
- 四锁、尾帧+资产、抽卡补救，都是可复现的工程做法
- "提示词越复杂模型越跑偏"符合实际观察

**局限**
1. **全部是口述经验，零数据**：没有成功率、返工次数、耗时统计
2. **强依赖特定工具链**：Grok + 特定生图/生视频平台，换工具需重验
3. **无失败归因体系**：知道"加参考图有用"，但没解释什么时候加、加几张、加什么类型的图最有效
4. **质量判定主观**："效果好""像真人"没有可量化标准
5. **部分内容属平台规避技巧**（未成年/版权），不适合作为方法论沉淀
6. **口语冗余高**：21,000 字里约三成是重复、口头禅、现场噪音
