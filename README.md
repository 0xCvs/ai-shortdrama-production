# ai-shortdrama-production

AI 短剧制作的**排障型技能包**：13 个可调用能力，按「症状」而不是按「章节」组织。

来源是一位从业者 85 分钟直播课的口述经验，用 [cangjie-skill](https://github.com/kangarooking/cangjie-skill) 蒸馏成可执行的能力卡。它解决的不是「怎么做一部片子」，而是**「已经卡住了怎么救」**。

## 它解决什么问题

| 症状 | 对应能力 |
|---|---|
| 提示词写对了，画面就是不对 | 提示词失效时转用图像参考 |
| 提示词越写越长，效果反而变差 | 提示词精简原则 |
| 反复抽卡，姿势出不来 | 静态姿势图前置 |
| 视频参考后角色串脸、尺寸变了 | 视频参考防串脸 |
| 多人场景堆不下、人物穿模 | 多人场景重构 |
| 两卡接不上、下一卡人物变了 | 尾帧衔接 |
| 整段有穿帮，不想重跑 | 抽卡补救：截可用帧 |
| 约束太多，怎么聊都生不出来 | 复杂设定先做主体图 |
| 群像场面，主角丢了 | 九宫格背景 + 单独主角 |
| 插入画面假 | 插入画面单独生成再拼 |
| 参考视频是外语，声音不对 | 音效替代：去掉参考音频自己写 |
| 模型变慢、漏信息、不思考 | 上下文窗口重置 |
| 封面人物错乱、版式难看 | 封面参考法 |

## 三个最有价值的判断

1. **说不清就丢图**——可见信息（外观、姿态、位置）用参考图，不可见信息（声音、节奏、情绪强度）才写字。同一份提示词反复不对，说明通道选错了，不是措辞问题。
2. **接不上就带资产**——下一卡除了上一卡尾帧，人物资产必须同时放进去，否则人物会变。
3. **全错了就截那一帧**——三十秒里总有几秒不穿帮，截下来当新起点，不要整段重跑。

## 安装

整个目录是一个标准 Agent Skill。放到技能目录即可：

```bash
# Claude Code
git clone <repo> ~/.claude/skills/ai-shortdrama-production

# DSH / 其他 agent
git clone <repo> ~/.agents/skills/ai-shortdrama-production
```

目录结构：

```
SKILL.md                      入口：触发条件、5 条核心原则、能力路由表
references/
  overview.md                 全书概览（18 条方法单元 + 批判与局限）
  capability-index.md         13 个能力完整索引（意图 + 关键词）
  cheatsheet.md               13 条一句话规则速查
  glossary.md                 行话对照（丢参考 / 抽卡 / 穿帮 / 四锁 …）
  capabilities/*.md           13 张能力卡
```

## 使用

说症状就行，agent 会按路由表自动加载对应能力卡：

```
六个人怎么排，老是穿模
两卡接不上，下一卡脸变了
提示词改十遍了还是不对
```

每张能力卡固定六段：`R 原文摘录` → `I 我的理解` → `A1 案例` → `A2 与相邻能力的区分` → `E 执行方式` → `B 边界`。

想通读全部内容：`docs/全文预览.md`。

## 边界

- 只覆盖**已有剧本与资产、卡在生成或剪辑阶段**的情况。从零写剧本、改编小说不在范围内。
- 原文是口述经验，**没有成功率、返工次数、耗时等任何数据**，全部结论为定性描述。
- 强依赖特定工具链（原文使用 Grok + 特定生图生视频平台），换模型后需要重新校准。
- 「四锁」原文称四项实列五项，且没有说明用什么工具实现——能力卡里只作为约束维度清单使用。
- 原文未给的参数，能力卡中标在 `B 边界`，不做补全。
